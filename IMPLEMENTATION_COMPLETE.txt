## 📞 SUPPORT & TROUBLESHOOTING

### Common Issues:

**Charts not showing:**
1. Check `console.log(depenses)` in browser
2. Verify ApexCharts CDN loaded
3. Check container element exists

**API returns 404:**
1. Verify routes: `php bin/console debug:router`
2. Check method name matches
3. Restart server

**Mobile looks broken:**
1. Check viewport meta tag
2. Verify responsive CSS
3. Test with device emulator
